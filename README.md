# 📚 WNTK Library System (ระบบห้องสมุด WNTK)

ระบบจัดการห้องสมุดดิจิทัล: ยืม-คืนหนังสือ บันทึกคะแนนนักเรียน สแกนบาร์โค้ด และแลกของรางวัล  
พัฒนาด้วย **Google Apps Script**, **Google Sheets** และพร้อมเปิดใช้งานผ่าน **GitHub Pages**

---

## 📁 ไฟล์ทั้งหมดในโปรเจกต์นี้

1. **`Code.gs`** : โค้ดหลังบ้าน Apps Script สำหรับจัดการฐานข้อมูล Google Sheets และ API (`doPost`)
2. **`Page.html`** : โค้ดหน้าเว็บสำหรับใส่ในตัวแก้ไขของ Google Apps Script
3. **`index.html`** : โค้ดหน้าเว็บฉบับปรับแต่งพิเศษสำหรับเปิดบน **GitHub Pages** (มีระบบเชื่อมต่อ Apps Script อัตโนมัติ)
4. **`README.md`** : คู่มือการตั้งค่าและการใช้งาน

## 🚀 วิธีตั้งค่าและการนำขึ้น GitHub

### ขั้นตอนที่ 1: ตั้งค่า Google Apps Script
1. เปิด Google Spreadsheet ที่สร้างตารางไว้
2. ไปที่เมนู **ส่วนขยาย (Extensions)** -> **Apps Script**
3. คัดลอกโค้ดจาก `Code.gs` ไปวางในไฟล์ `Code.gs`
4. กดเครื่องหมาย `+` ด้านข้างตัวแก้ไข -> เลือก **HTML** -> ตั้งชื่อว่า `Page` แล้วนำโค้ดจาก `Page.html` ไปวาง
5. กดปุ่มบันทึก (แผ่นดิสก์)
6. กด **การทำให้ใช้งานได้ (Deploy)** -> **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
   - ชนิด: **เว็บแอป (Web app)**
   - ดำเนินการในฐานะ: **ฉัน (Me)**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน (Anyone)** *(สำคัญมาก)*
7. กด **ทำให้ใช้งานได้ (Deploy)** แล้วคัดลอก **URL เว็บแอป** เก็บไว้

---

### ขั้นตอนที่ 2: นำโค้ดขึ้น GitHub
1. เข้าเว็บ [github.com](https://github.com) แล้วกด **New repository**
2. ตั้งชื่อโปรเจกต์ เช่น `wntk-library` แล้วกด **Create repository**
3. กดปุ่ม **Add file** -> **Upload files**
4. ลากไฟล์ทั้ง 4 ไฟล์ (`Code.gs`, `Page.html`, `index.html`, `README.md`) ไปวาง
5. กด **Commit changes**

---

### ขั้นตอนที่ 3 (ทางเลือก): เปิดหน้าเว็บฟรีผ่าน GitHub Pages
1. ในไฟล์ `index.html` แก้ไขบรรทัด:
   ```javascript
   const GAS_WEB_APP_URL = "นำ URL เว็บแอปจากขั้นตอนที่ 1 มาใส่ตรงนี้";
   ```
2. ไปที่เมนู **Settings** ของ Repository บน GitHub -> เลือกหัวข้อ **Pages**
3. ที่หัวข้อ **Branch** เลือกกิ่ง `main` แล้วกด **Save**
4. รอประมาณ 1-2 นาที คุณจะได้ลิงก์เว็บไซต์ เช่น `https://your-username.github.io/wntk-library/` สำหรับเปิดใช้งานได้ทุกอุปกรณ์!
